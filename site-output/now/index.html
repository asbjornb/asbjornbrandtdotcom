💻 Tech

  • Still awestruck by what we can now do with agents. We're working through our backlog at work at incredible speed while also improving everything surrounding how we build software. I've personally set up agents that watch our deployment and notify us if anything is out of order, agents that help diagnose alerts quickly, agents that help manage our dependencies. All of this works on top of existing non-agentic good practices around observability, dependency management etc. No reason to have agents update dependencies when Renovate does that better, but when Renovate fails or when we see a new major an agent can help fix it or see if we can get more value from the integration.
  • Playing around with Omarchy - liking it so far. Planning to switch my work laptop to linux too - it just works better with modern tooling imo.
